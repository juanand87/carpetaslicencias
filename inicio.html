🚗 Carpetas de Licencias

Sistema Municipal de Solicitudes

1 Instalación Base

Sigue estos pasos iniciales:

  • XAMPP debe estar corriendo (Apache + MySQL)
  • Ejecutar script SQL: sql/database.sql
  • Verificar conexión en: config/database.php

2 Configuración SMTP

Para enviar correos:

  • Acceder como admin
  • Ir a: Administración > Configuración SMTP
  • Si usas Gmail, generar contraseña aquí:
    https://myaccount.google.com/apppasswords

3 Primer Funcionario

Crear un usuario para atender solicitudes:

  • Admin > Gestionar Funcionarios
  • Crear nombre, correo y contraseña
  • Guardar

4 ¡Listo!

El sistema está listo para usar. Puedes:

  • Crear solicitudes (sin login)
  • Gestionar como funcionario
  • Administrar el sistema
ℹ️ Importante: Cambiar la contraseña del admin (admin123) es altamente recomendado después del primer acceso.
